# Korean Keyboard Practice (한국어 키보드 연습)

Keyboard layout familiarization exercise. The word 산화 means "oxidation."

## Notes

This file was used for practicing the Korean keyboard layout (두벌식/Dubeolsik), getting familiar with consonant and vowel key positions.

### Korean Keyboard Layout Reference

```
ㅂ ㅈ ㄷ ㄱ ㅅ  ㅛ ㅕ ㅑ ㅐ ㅔ
ㅁ ㄴ ㅇ ㄹ ㅎ  ㅗ ㅓ ㅏ ㅣ
ㅋ ㅌ ㅊ ㅍ ㅠ  ㅜ ㅡ
```

Shift layer adds tense consonants: ㅃ ㅉ ㄸ ㄲ ㅆ and compound vowels: ㅒ ㅖ
